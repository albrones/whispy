Install

One command installs Whispy on macOS and Linux. Tick the steps as you go; your progress is remembered in this browser.

One-line installer

curl -fsSL https://raw.githubusercontent.com/albrones/whispy/main/scripts/bootstrap.sh | bash

On macOS it installs Rust and cmake if they are missing, builds and signs Whispy V2.app into /Applications, and launches it. An older Whispy.app is quit and moved to the Trash. Source lives in ~/.local/share/whispy. Run the command again to update.

On Linux it installs the build tools Whispy needs with apt, dnf or pacman (sudo asks for your password) and Rust if it is missing, builds Whispy, installs it as ~/.local/bin/whispy2 and runs it as the systemd --user unit whispy2.service, which starts with your session. An older Python install of Whispy is stopped and removed; your settings are kept. Source lives in ~/.local/share/whispy. Run the command again to update.

Checklist

  1. Run the one-line installer above. If the Xcode Command Line Tools are missing, it opens their installer: let it finish, then run the command again. The first build takes a few minutes. To do it by hand (with Rust and cmake installed): 
    git clone https://github.com/albrones/whispy.git
cd whispy && make reinstall   # builds, signs, installs and launches Whispy V2.app
  2. Models. On first launch Whispy downloads its speech models, about 1.2 GB (a notification says so). The menu says Ready when you can dictate.
  3. Microphone. At your first dictation macOS shows a Whispy V2 prompt: click Allow.
  4. Accessibility. System Settings → Privacy & Security → Accessibility → enable Whispy V2. Without it the text is transcribed but never typed.
  5. Input Monitoring. System Settings → Privacy & Security → Input Monitoring → enable Whispy V2. It is needed to detect the Fn key.
  6. With Fn as the trigger, set System Settings → Keyboard → Press 🌐 key to → Do Nothing, or every tap also opens the emoji picker.
  7. Restart Whispy from its menu bar icon (Restart) so the new permissions apply.
  8. Switch on Start at login in the menu bar menu.

Whispy is signed with a free, local self-signed certificate, so macOS remembers the permissions across updates. It keeps your settings in ~/.config/whispy/config.json.

  1. Know your session. X11: Whispy listens to Right Ctrl itself and shows a tray icon. Wayland: no app may listen to a global key, so a key binding of your compositor drives Whispy (whispy2 send start on press, whispy2 send stop on release); there is no tray icon and alerts arrive as notifications.
  2. Run the one-line installer above. The first build takes several minutes. Without apt, dnf or pacman, or to install the packages yourself (then set WHISPY_SKIP_SYSTEM_PACKAGES=1): 
    sudo apt install git curl build-essential cmake clang libclang-dev pkg-config libasound2-dev libxkbcommon-dev libnotify-bin xclip   # Debian/Ubuntu
sudo dnf install git curl gcc gcc-c++ make cmake clang clang-devel pkgconf-pkg-config alsa-lib-devel libxkbcommon-devel libnotify xclip   # Fedora
sudo pacman -S --needed git curl base-devel cmake clang pkgconf alsa-lib libxkbcommon libnotify wl-clipboard   # Arch / Omarchy
    Under Wayland, take wl-clipboard instead of xclip.
  3. Models. On first launch Whispy downloads its speech models, about 1.2 GB, into ~/.whispy/models. Check that it runs and is ready: 
    systemctl --user status whispy2
whispy2 send status   # "models_loaded":true when you can dictate
  4. Wayland, outside Omarchy: bind a key of your compositor to whispy2 send start (press) and whispy2 send stop (release), or one key to whispy2 send toggle. For sway: 
    bindsym --no-repeat Control_R exec whispy2 send start
bindsym --release Control_R exec whispy2 send stop
  5. On Omarchy (Hyprland): the installer links the omarchy-dictation-whispy backend into ~/.local/bin and the Whispy bar widget into ~/.config/omarchy/plugins, and puts its icon on the right of the bar. Select the backend once, then hold the dictation key (Right Option by default; pick another in the Whispy panel). If Whispy is not running, the key shows « Whispy is not answering ». 
    omarchy-dictation-use whispy && hyprctl reload

On Linux the text is always typed, one key at a time (XTest under X11, the virtual-keyboard protocol under Wayland), so it reaches terminals too. Under X11 the tray icon is optional: without a tray host in your panel, Whispy posts one notification and runs without it (see troubleshooting).

First run: the models

Whispy transcribes with nvidia/parakeet-tdt-0.6b-v3, run on your CPU, and retries a dictation Parakeet heard nothing in with whisper small. Both are downloaded once at first launch from pinned revisions, each checked against its SHA-256: about 1.2 GB together, in ~/.whispy/models. Parakeet uses about 1.4 GB of memory while loaded.

It transcribes 25 languages and detects the language automatically: Bulgarian, Croatian, Czech, Danish, Dutch, English, Estonian, Finnish, French, German, Greek, Hungarian, Italian, Latvian, Lithuanian, Maltese, Polish, Portuguese, Romanian, Slovak, Slovenian, Spanish, Swedish, Russian and Ukrainian. Other languages will not transcribe.

Not working? Read ~/.whispy/v2/whispy2.log and journalctl --user -u whispy2, or see Troubleshooting.

Uninstall

curl -fsSL https://raw.githubusercontent.com/albrones/whispy/main/scripts/bootstrap.sh | bash -s -- --uninstall
