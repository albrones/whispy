Usage

Hold the trigger, speak, release. The text is typed into the focused field.

Dictating

  1. Put the cursor in any text field.
  2. Hold the trigger key: Fn on macOS, Right Ctrl under X11, the key your compositor binds under Wayland (Right Option by default on Omarchy). A sound confirms recording, and a pill with your voice's level shows at the bottom of the screen.The tray icon turns into a red dot under X11; on Omarchy, a waveform pill shows at the bottom of the screen.
  3. Speak.
  4. Release the key. The text is transcribed and inserted. A press under 0.3 s is ignored.

On macOS you can change the key from the menu bar (Settings → Trigger): Fn, Right Command, Right Option or F13. Under X11 the key is Right Ctrl: it is only listened to, never grabbed, so it still works as a modifier, and Right Ctrl + another key is a shortcut, not a dictation. Under Wayland your compositor's binding calls whispy2 send start and whispy2 send stop (see Install).

Hold or toggle

The default hold mode is push-to-talk. With trigger_mode set to "toggle", press the trigger once to start and again to stop. In toggle mode, type_while_speaking (on by default) types the words while you speak, about two seconds behind your voice: a word is typed once it is stable, and nothing typed is ever erased or rewritten. Switching windows mid-dictation scatters the text across them.

Numbers

Numbers dictated in French are written in digits: « quatorze heures trente » becomes « 14 h 30 » and « dix pour cent » becomes « 10 % ». « un » and « une » stay in letters, and English text is left as is.

Menu bar, tray and Omarchy bar

Whispy lives in the menu bar, as a braille waveform that moves while it records or transcribes. Its menu shows the status and holds Copy to clipboard, Toggle mode, Type while speaking, Trigger and Start at login, then Restart and Quit, with Update available (X.Y.Z) above them when a new release is out. If a permission is missing, a ⚠ Missing permission — fix in System Settings… row appears.

Under X11, Whispy shows its state in the system tray: a grey ring at rest, a red dot while it listens; its menu shows the status and Quit, with Update available (X.Y.Z) when a new release is out. Without a tray host, Whispy posts one notification and runs on without the icon. Alerts are desktop notifications (notify-send).

On Omarchy, the installer puts a Whispy icon on the right of the bar: a still waveform when ready, a green moving one while it listens, a moving one while it transcribes, greyed when Whispy is stopped. Click it for a panel with a switch that starts or stops Whispy (its systemd --user unit), the dictation key (Right Option, Right Ctrl or F9 held, or Left Option + Space to toggle), Start at login, Update available (X.Y.Z) when a new release is out, and your last dictation (click to copy it; Whispy keeps it in memory only). A new key applies at once, even while Whispy is stopped. While you speak, a waveform pill shows at the bottom of the screen; it never takes the keyboard focus. The chosen key is written to ~/.config/whispy/shortcuts.lua, which Omarchy loads while Whispy is the dictation backend: a dictation key you bound by hand in ~/.config/hypr/bindings.lua still applies on top of it.

Logs

Whispy writes one log, with one line per dictation (never its text), rotated past 5 MB:

tail -f ~/.whispy/v2/whispy2.log

The service's own output is in the journal: journalctl --user -u whispy2 -f.

Restart

Menu bar → Restart, or quit and reopen /Applications/Whispy V2.app.

systemctl --user restart whispy2

On Omarchy, the switch at the top of the Whispy panel stops and starts it.

Uninstall

If you installed with the one-liner:

curl -fsSL https://raw.githubusercontent.com/albrones/whispy/main/scripts/bootstrap.sh | bash -s -- --uninstall

It keeps your settings (~/.config/whispy) and the models (~/.whispy).

Or by hand:

# 1. Quit Whispy (menu bar → Quit), then delete the app (this also drops the Start at login item)
rm -rf "/Applications/Whispy V2.app"
# 2. Optional: wipe the models, logs and settings
rm -rf ~/.whispy ~/.config/whispy

Permission grants are tied to the Whispy V2.app identity. After reinstalling, macOS may ask you to approve them again.

Or by hand:

systemctl --user disable --now whispy2
rm -f ~/.config/systemd/user/whispy2.service ~/.local/bin/whispy2 ~/.local/bin/whispy ~/.local/bin/omarchy-dictation-whispy
rm -f ~/.config/omarchy/plugins/whispy-panel
# Optional: wipe the models, logs and settings
rm -rf ~/.whispy ~/.config/whispy

Local control

Whispy opens no network port. It listens on a Unix socket readable only by you, ~/.whispy/v2/control.sock, one request per line, one JSON line back:

whispy2 send status

status reports the state, whether the models are loaded, the last problem and the input level; start and stop act like pressing and releasing the trigger, toggle like one press in toggle mode; last returns the text of the last dictation, kept in memory only; check-update looks for a new release now, and update installs the one the menu offers (status carries that row as update, only while there is one). whispy2 send exits 0 on an answer, 1 when Whispy refuses, 2 when no Whispy answers. Any socket client works too:

printf 'status\n' | nc -U ~/.whispy/v2/control.sock

The bundled command is "/Applications/Whispy V2.app/Contents/MacOS/whispy2" send status.

The models

Whispy transcribes with nvidia/parakeet-tdt-0.6b-v3, int8-quantized to ONNX and run on your CPU. When Parakeet hears nothing in a dictation that holds voice, whisper small tries it again. Both download automatically at first launch (about 1.2 GB together) into ~/.whispy/models; there is nothing to choose, so there is no model setting. Parakeet uses about 1.4 GB of memory while loaded; whisper small loads only when needed and is freed when idle.

No language setting

The model detects the language of each utterance and copes with switching languages mid-recording, so there is no language setting. See the supported languages.

Short sounds and silence are ignored

Given silence or room noise, the model answers with a short filler such as Yeah. or Okay., which would be typed into whatever you have focused. Two gates run first, and a clip must clear both:

  • Loudness. Anything below 0.005 normalized RMS is discarded: a muted mic, a misfire, a quiet room.
  • Voice detection. Anything with under 0.20 s of detected voice is discarded: steady noise, a fan, mains hum.

Whispy never filters by what was said, since Okay. and No. are legitimate one-word dictations. A dictation of half a second or more in which the microphone heard nothing at all says « Microphone heard nothing », with the input device's name.

FAQ

Will Whispy start automatically at each reboot?

Yes, if you enable Start at login in the menu bar menu (it uses SMAppService, no LaunchAgent).

Yes. The installer enables the systemd --user unit whispy2.service, which starts with your session. Turn it off with systemctl --user disable whispy2, or Start at login in the Omarchy panel.

How do I update Whispy?

From its menu (macOS menu bar, Linux tray icon or Omarchy panel). Whispy looks for a newer release when it starts, then once a day. While it is up to date, or offline, the menu shows nothing about updates. When a release is out, an Update available (X.Y.Z) row appears; nothing is installed until you click it. That click installs the release and restarts Whispy (the install log is ~/.whispy/v2/update.log). Dictation keeps working meanwhile. The row then reads Updating to X.Y.Z… until Whispy restarts on the new version; if the install fails, it reads Update to X.Y.Z failed: reason — try again, and a click tries again.

The update never asks for a password: when a new release needs system packages (sudo), the row shows the install command to run in a terminal instead.

Or run the one-line installer again. It pulls the latest code into ~/.local/share/whispy, then:

rebuilds Whispy V2.app when the code changed, replaces it in /Applications and relaunches it. From your own checkout, make reinstall does the same.

rebuilds whispy2, replaces ~/.local/bin/whispy2 and restarts the unit. From your own checkout, make reinstall does the same.

Can I use a different model or language?

No. Whispy ships one model, nvidia/parakeet-tdt-0.6b-v3, which covers 25 languages and detects them automatically. There is no model or language setting. Speech outside those languages will not transcribe.

I spoke and nothing was typed.

The clip may have been discarded: a tap rather than a hold (under 0.3 s), near-silent, or with too little detected voice. ~/.whispy/v2/whispy2.log has one line per dictation with its outcome. A muted or wrong input device is another usual cause: Whispy opens the current default input at each dictation. Why short clips are ignored. See Troubleshooting.

How do I know whether Whispy is running?

Its menu bar icon shows it.Its tray icon (X11) or Omarchy bar icon shows it, or systemctl --user status whispy2. Either way, whispy2 send status answers when it runs.
