Configuration

Whispy reads ~/.config/whispy/config.json. Every key is optional: anything missing falls back to its default, and an invalid value is replaced by the default with a warning in the log.

Config builder

Set the values you want and copy the result. Only the keys you changed are shown; merge them into your existing config.json, then restart Whispy.

This builder needs JavaScript. Without it, use the reference table below to write the JSON by hand.

How chunking works

While you speak, Whispy cuts the recording into chunks at pauses and transcribes each one. This illustration shows where the cuts fall for the current pause_ms, min_speech_s, soft_gap_ms, min_chunk_s and max_chunk_s.

The visualizer needs JavaScript. In short: a pause longer than pause_ms closes a chunk once it holds min_speech_s of speech; a chunk longer than max_chunk_s is cut at the next gap of soft_gap_ms, or unconditionally at 1.5 times max_chunk_s.
