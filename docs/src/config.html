Configuration

Whispy reads ~/.config/whispy/config.json when it starts. Every key is optional: anything missing falls back to its default, and an invalid value is replaced by the default with a note in the log. When Whispy saves a setting, it changes that key only and leaves every other key as it found it.

On macOS every key below is also in the menu bar menu, where a change applies to the next dictation without a restart.

On Linux, edit the file, then restart Whispy: systemctl --user restart whispy2. On Omarchy, pick the dictation key in the Whispy bar panel instead.

Config builder

Set the values you want and copy the result. Only the keys you changed are shown; merge them into your existing config.json, then restart Whispy.
