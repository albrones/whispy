## Default engine and strategy (criterion 7)

Rule: a configuration that invents text on non-speech is out (it would be typed into the user's window). Among the rest, one whose reference WER is not worse than V1's comes first; then the most lost speech clips with text, the most lost clips with text, the lowest WER over reference and quiet clips, the lowest ~5 s p95.

**No configuration matches V1's reference WER**; the pick is the best of the others by the same order.

**Pick: parakeet then whisper / padded** — lost speech clips with text –, all lost clips with text 6/20 (30%), reference WER 3.7%, quiet WER 6.3%, invented on non-speech 0, ~5 s sentence p95 0.15 s.

`whispy_core::Pipeline::load_default()` uses `DEFAULT_ENGINE`/`DEFAULT_FALLBACK`/`DEFAULT_STRATEGY` = parakeet then whisper / padded, which matches the pick.
