## Default engine and strategy (criterion 7)

Rule: a configuration that returns text on non-speech, or on a clip the user labelled noise, is out (it would be typed into the user's window). Among the rest, one whose reference WER is not worse than V1's comes first; then, on the user's labelled clips, one that holds criterion 3, the most lost speech clips with text and the fewest word errors; then the most lost clips the oracle heard speech in with text; only without labelled clips, the most lost clips with text (unlabelled, so text there may be invented); then the lowest WER over reference and quiet clips, the lowest ~5 s p95.

**No configuration matches V1's reference WER**; the pick is the best of the others by the same order.

**Pick: parakeet then whisper / padded** — labelled clips: lost speech with text 6/7 (86%), noise with text 0, WER 15.1% against V1's 16.9%; lost speech clips with text (oracle) –, all lost clips with text 0/20 (0%), reference WER 3.7%, quiet WER 6.3%, invented on non-speech 0, ~5 s sentence p95 0.15 s.

`whispy_core::Pipeline::load_default()` uses `DEFAULT_ENGINE`/`DEFAULT_FALLBACK`/`DEFAULT_STRATEGY` = parakeet then whisper / padded, which matches the pick.
